# Levothyroxine

Welcome to Mechanism Diligence.
Let’s talk about levothyroxine, which is the generic name.
Synthroid is a brand name, and it may be the name you already know.

## What is this medicine?

We’re following a tablet that replaces too little thyroid hormone in adults. Hormones are chemical messages. Thyroid hormone helps control heat, heart activity, and how the body uses food. The drug supplies a missing message. It does not fix a damaged thyroid gland.

## How does it get to work?

The tablet dissolves, and the drug passes from the gut into blood. Food and some other drugs can change how much gets in. Blood carries the hormone to tissues. Proteins help it enter cells.

## How does it work?

The tablet supplies a hormone called T4. Cells can change some T4 into a more active form, T3.

T3 binds to proteins called receptors inside cells. This changes how cells read some of their genes. Genes hold instructions for making proteins. Some instructions get read more; others get read less.

These changes help set the pace of body functions. Each tissue controls how much active hormone it gets and how it responds. The hormone does not speed up every cell in the same way.

## How can it help and cause harm?

The right amount restores a signal the body needs. Too little leaves the shortage in place. Too much can cause a fast or uneven heartbeat. It can also weaken bones. More is not better.

## What is still unclear?

Some people still feel unwell when blood tests reach the expected range. There can be several causes. Symptoms matter, but they do not always mean the dose should rise.

## How long does it work?

T4 stays in the body for days. A dose change may take four to six weeks to reach its full effect. Serious new symptoms still need prompt care.

## What should we know about doses and risks?

The dose is chosen for each person. Food timing and other drugs matter. The type of thyroid problem also determines which blood tests guide treatment.

Do not use it if a low supply of adrenal hormones has not been treated. These hormones help the body handle stress. Starting thyroid hormone first can cause a life-threatening crisis.

Do not use it to lose weight. Too much can be deadly. These tablets cannot treat a thyroid emergency with coma; that needs hospital care.

## What is the main idea?

The tablet replaces T4. Cells change some to T3, then use that signal to control their work.
